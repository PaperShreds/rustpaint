# Environment maps

Both maps are from Poly Haven at 1K resolution, licensed
[CC0](https://creativecommons.org/publicdomain/zero/1.0/): free to use for any
purpose, no attribution required. They are embedded in the binary as the
built-in viewport lighting (View > Environment).

- `je_gray_02_1k.hdr`: "J&E Gray 02" by Greg Zaal
  (https://polyhaven.com/a/je_gray_02). Outdoors, trees and sun. The default.
- `studio_small_09_1k.hdr`: "Studio Small 09"
  (https://polyhaven.com/a/studio_small_09). A neutral photo studio.
