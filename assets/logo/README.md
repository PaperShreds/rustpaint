# Logo

- `logo.svg`: the RustPaint logo. `icon.png` is the same drawing at 256x256
  pixels, used as the window icon (rendered from the SVG with
  `rsvg-convert -w 256 -h 256 logo.svg -o icon.png`).

The black cog ring in the logo is taken from the Rust programming language
logo, which is owned by the [Rust Foundation](https://rustfoundation.org) and
distributed under the Creative Commons Attribution 4.0 International license
([CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)).

Changes: only the outer cog ring of the original is used; it was resized and
combined with a colour-gradient disc in the middle.
